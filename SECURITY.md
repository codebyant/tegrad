# Security Policy

`tegrad` runs on the user's machine and handles cryptographic keys, so we take vulnerability reports seriously.

## Reporting a vulnerability

Please report privately to **security@tegramc.com**. Do not open a public issue or pull request for a vulnerability.

Include what you found, how to reproduce it, the affected version, and the impact you expect. We will acknowledge your report and keep you updated until it is fixed. Please give us reasonable time to release a fix before any public disclosure.

## Supported versions

Only the latest release of each update channel receives security fixes.
